# Novamera IP Transferability Agent

Interactive dashboard analyzing Propel Labs' Novamera work product portfolio for IP transferability across mining tech and adjacent industries.

## Live Dashboard

**[View Dashboard →](https://propel-labs.github.io/ip-transferability-dashboard/)**

## What This Analyzes

- **10 Work Products** from the Novamera engagement
- **10 Target Industries** (4 mining, 6 adjacent)
- **Legal status** under current MSA terms
- **Revenue potential** for transferable IP
- **Strategic recommendations** for platform packaging

## Views

| View | Description |
|------|-------------|
| **Dashboard** | Portfolio overview with legal status, transferability ratings, and key findings |
| **Heatmap** | 10×10 matrix of work product × industry fit scores with click-to-expand detail |
| **Industries** | Drill into each target market to see which products fit best |
| **Strategy** | Three-tier packaging roadmap, beachhead recommendations, and critical risks |

## Key Findings

- **5 of 10** work products have HIGH transferability potential
- **$7–14M ARR** total addressable revenue from transferable IP
- **3 products** already qualify as Generic Work Product under current MSA
- **4 products** require MSA renegotiation to retain IP rights
- **Oil & Gas** is highest-value adjacent market (geostatistics framework is mathematically identical to reservoir characterization)
- **Mining Services** is fastest path to revenue (SRK, WSP, Golder need these tools today)
